# Canonical papers

The Zenodo upload contains exactly these two canonical preprints and their source resources:

- `personavoice_preprint.pdf` / `personavoice_preprint.tex`: language provenance and selective planning.
- `personavoice_speech_preprint.pdf` / `personavoice_speech_preprint.tex`: measured one-second speech results.
- `personavoice.bib`, `tacl-style/`, `tmlr-style/`, and `figures/`: LaTeX dependencies and publication figures.

Historical anonymous drafts, protocol-only documents, and integrated outlines are intentionally excluded from the canonical release.

Build either source from this directory with `pdflatex`, `bibtex`, and two
further `pdflatex` passes. The checked-in PDFs are the release renderings.
